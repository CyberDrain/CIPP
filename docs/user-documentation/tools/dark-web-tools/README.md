# Dark Web Tools

The Dark Web Tools check email addresses and domains against known breach data. Tenant Breach Lookup lists the accounts in a tenant that appear in known breaches, and Breach Lookup checks a single address or domain on demand.

Both breach lookups need the `CIPP.BreachLookup` permission. The built-in roles all carry it, but a custom role built with only the permissions needed to sign in does not.
