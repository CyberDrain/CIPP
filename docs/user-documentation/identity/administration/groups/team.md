# View Team

A team is a Microsoft 365 group, so its pages are tabs of the [group page](group.md): **Team** and **Channels** appear next to **View Group** and **Intune Assignments** when the group has a team. **View Team** on the [Teams](../../../teams-share/teams/list-team/README.md) list opens the **Team** tab. Members and owners are managed on **View Group**. The switcher next to the team name moves to another team, and the header opens the team in Microsoft Teams. Each channel opens its own [channel page](channel.md).

## Actions

| Action         | Description                                                                                                                                              |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Edit team settings | Changes what members and guests can do, the messaging options and the Giphy, sticker and meme options. Opens with the current settings. Greyed out while the team is archived. |
| Archive Team   | Makes the team read-only: members can still read it, but nobody can post or change it. Archiving takes a few minutes to finish. Shown on an active team. |
| Unarchive Team | Makes an archived team usable again. Shown on an archived team.                                                                                          |

## Team

**Team** shows the visibility, description, owners, how many members and guests the team has, its channels by type, and whether it is archived.

The settings are grouped into **Member permissions**, **Guest permissions**, **Messaging** and **Fun**. Change them with **Edit team settings** in the Actions menu.

## Channels

The team's channels with their type, how many members a private or shared channel has and who owns it, how many tabs it has, whether it is archived, and its description. Select a channel's name to open it. Channel names, members and tabs are shown; messages and files are not.

**Add channel** creates a channel:

| Type     | Who is in it                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------- |
| Standard | Everyone in the team.                                                                             |
| Private  | Only the people added to it. Choose a team member as its owner, then add more people on its page. |
| Shared   | Only the people added to it. Choose an owner, then add people from the organisation on its page.  |

| Action         | Description                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------- |
| View channel   | Opens the [channel page](channel.md).                                                                               |
| Delete channel | Deletes the channel and its conversations. Greyed out for the General channel, which Teams does not let you delete. |
