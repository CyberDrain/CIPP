# View Channel

Opens from **View channel** on a team's **Channels** tab. It keeps the group's tabs, and the switcher next to the channel name moves to another channel in the same team. The header shows the channel type and team, and opens the channel in Microsoft Teams or its files location in SharePoint.

## Actions

| Action            | Description                                                                                                    |
| ----------------- | -------------------------------------------------------------------------------------------------------------- |
| Edit channel      | Changes the channel name and description. Not shown for the General channel, which Teams does not let CIPP edit. |
| Edit moderation   | Shown for standard channels: sets who can start a post (everyone, or only owners and moderators), who can reply (everyone, or only the author and moderators), and whether bots and connectors can post. |
| Archive channel   | Makes the channel read-only: people can still read it, but nobody can post. Not shown for the General channel. |
| Unarchive channel | Makes an archived channel usable again.                                                                        |
| Delete channel    | Deletes the channel and its conversations. Not shown for the General channel.                                  |

## Channel

The channel type, description, when it was created and whether it is archived.

## Moderation

Shown for standard channels: who can start a post and reply, and whether bots and connectors can post. Change it with **Edit moderation** in the Actions menu.

## Members

Shown for private and shared channels, with each person's role: owner, member or guest.

**Add members** adds several people at once, as members or owners:

- A **private** channel can hold the team's own members, guests included. Guests can only be members, never owners.
- A **shared** channel can hold anyone in the organisation, not only the team's members. People from other organisations are not added here.

| Action              | Description                                                                         |
| ------------------- | ----------------------------------------------------------------------------------- |
| Make owner          | Makes a member an owner of the channel. Not available for guests.                   |
| Make member         | Makes an owner a regular member of the channel.                                     |
| Remove from channel | Removes the person from the channel. Select several people to remove them together. |

## Tabs

The tabs pinned to the channel, with the app behind each one. A website tab also shows its address.

**Add website tab** pins a web address to the channel: an external site, or a SharePoint or OneDrive link to share files with the channel. Addresses must start with `https://`.

| Action         | Description                            |
| -------------- | -------------------------------------- |
| Rename tab     | Changes the tab's name.                |
| Change address | Points a website tab at a new address. |
| Remove tab     | Removes the tab from the channel.      |
