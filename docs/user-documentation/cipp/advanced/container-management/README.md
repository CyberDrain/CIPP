# Container Management

Container Management covers everything specific to the CIPP application container on a self-hosted instance: which image and version are running, the release channel and automatic update behavior, the custom domains bound to the app service, the container's own log stream, and the health of its background worker pools.

These pages are limited to users with the `superadmin` role.

{% hint style="warning" %}
Note that it may take some time for a role change to take effect.
{% endhint %}
