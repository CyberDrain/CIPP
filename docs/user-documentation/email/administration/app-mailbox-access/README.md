# App Mailbox Access

Pages for the mailbox access Exchange Online gives applications in a tenant, which does not show as a permission or consent in Entra. App Mailbox Access has three tabs: the Exchange application roles applications hold, the application access policies that limit which mailboxes their Entra mailbox permissions reach, and the management scopes that roles can be limited to.

To see the same access for a single application, open the **Exchange** tab of [spid.md](../../../tenant/administration/applications/enterprise-apps/spid.md "mention").
