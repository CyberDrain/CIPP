# Global Secure Access

Pages for Microsoft Entra Global Secure Access web content filtering: the filtering policies and security profiles in each tenant, and the templates you deploy them from. A security profile filters traffic once a Conditional Access policy applies it. The Traffic Forwarding page manages the traffic forwarding profiles: whether each is enabled, who it applies to, the remote networks that use it, and the Internet Access custom bypass and acquire rules.
